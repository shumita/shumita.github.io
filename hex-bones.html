HEXES

Hexclosure: Creates a force field up to 10ft in radius. Conjuring a force field and keeping it up takes a lot of the user's energy. Currently in the posession of Alejandro Sielos.
Hexpire: the user can age/mature living things rapidly at will. Currently in the posession of Carlitos Huevos.
Hexclamation: allows the user to project their voice at will. Currently owned by Flordeliza Del Bosque.
Hexistential: Causes others to have a mental crisis about their own existence. Currently owned by Isa Huang.
Hextinguish: Allows the user to put out any fire within a 15ft radius of themself + user can withstand high temperatures without pain or damage. Currently in the posession of JingLi Del Azar
Hexchange: Allows the user to transform a body part into that of any creature. Currently owned by Lihua Teng.
Hextraterrestrial: provides the user with the ability to communicate with alien species. Currently in the posession of Ariel Sielos.
Hexceed: Provides the user with super strength. Currently owned by Leon Del Azar.
Hexalt: allows the user to increase the power of one (1) other Hex at a time. Currently owned by Luìs Reyes.
Hexpose: the user detects any lies said by others. Currently owned by Min Zheng.
Hexception: makes the user impervious to magic, including other Hexes. Currently owned by Meiying Chen.
Hexhaust: Allows the user to absorb other's energy at will. Currently in posession of Mara Yang.
Hexquine: Allows the user to transform their head into that of a horse. Currently owned by Estrella Pìa.
Hexcelerate: Allows the user to increase their speed. Currently in posession of Axel Romero.
Hextract: Using a cutting or slashing motion, the user can separate one concept/thing from another concept/thing for approximately one (1) minute at a time. The effect is reversed after the minute is over. Currently owned by Agent Ruishi.
Hexternalize: The user may create a projection that reflects their current emotions. Currently owned by Abel Pìa.
Hextravagant: the user may turn small objects into solid diamond at will. Current location unknown.
Hexcused: the user may teleport anywhere within a 15m radius. Current location unknown.
Hexternilize: the user can project magic constructs that reflect their own emotions. Currently owned by Abel Pìa.
Hexpel:The user can expel a chosen object out of a chosen area. Currently owned by Hēi Ai.
Hexam:Allows the user to force others into a test. Currently in the possession of Maya The Doll.
Hexpectation:The user will coincidentally show up where least expected. Currently owned by Santana.
Hexorcize:The user sees ghosts and can choose to push souls outside of a person's body. Currently in the posession of Xia Mengxi.
Hexpunge:The user can cast arrows that delete its target from existence. Currently owned by Xu Xun.
Hexquivalent:Using required materials, the user may create a replica of an object. The replica will have a different but equivalent function than the original. Currently in possession of Grimalgo.
